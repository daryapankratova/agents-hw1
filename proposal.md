# Proposal: Mini Study Task Tracker (tracker-v2.html)

## Цель
Создать автономный мини-трекер учебных задач на неделю, позволяющий пользователю управлять списком задач (добавление, удаление, отметка о выполнении), отслеживать суммарные часы и процент прогресса. Трекер должен работать полностью в одном HTML-файле без внешних зависимостей (CDN, библиотеки, API-ключи).

## Границы проекта
- **Область действия**: управление списком учебных задач, расчёт прогресса, фильтрация отображения, валидация ввода, адаптивный интерфейс.
- **Вне границ**:
  - Нет интеграции с внешними сервисами, календарями или учётными системами.
  - Нет сложной аналитики, графиков, экспорта/импорта данных.
  - Нет авторизации, ролей или многопользовательского режима.
  - Не требуется поддержка старых браузеров ниже современных стандартов (ES6+, CSS3).

## Контекст и предпосылки
Трекер ориентирован на быстрое использование в веб-браузере с мобильных устройств (минимальная ширина 390 px). Стартовый набор задач задаётся жёстко в коде, но пользователь может изменять его через интерфейс. Данные могут сохраняться в localStorage (если доступно), иначе работают в оперативной памяти.

## Критерии успеха
- Все операции (добавление/удаление/переключение done) реально изменяют внутреннее состояние.
- Валидация полей (название, часы) работает корректно, ошибки отображаются рядом с полями, данные формы сохраняются при ошибке.
- Расчёт прогресса соответствует формуле и не выдаёт NaN/Infinity.
- Фильтр влияет только на отображение списка, не меняя итоговые метрики.
- Интерфейс читаем на ширине 390 px, без горизонтального скролла.
- При отсутствии localStorage показывается понятное сообщение, работа продолжается в памяти.
