- [ ] Добавить понятные подписи для всех полей и кнопок.

## Verification Tasks (WHEN/THEN Checks)

- [ ] WHEN включён фильтр «активные», THEN список содержит только задачи с done=false; прогресс остаётся 25% (для стартового набора).
- [ ] WHEN введено пустое название (после trim), THEN задача не добавляется; видна ошибка рядом с полем названия; данные формы сохранены.
- [ ] WHEN введены пустые/отрицательные/некорректные часы, THEN задача не добавляется; видна ошибка рядом с полем часов; данные формы сохранены.
- [ ] WHEN все задачи удалены, THEN итоговые часы = 0 ч; прогресс = 0%; нет NaN/Infinity.
- [ ] WHEN задача «Практика» отмечена как выполненная, THEN прогресс становится 75% (6/8 часов).
- [ ] WHEN localStorage недоступен, THEN показано понятное сообщение; трекер работает в памяти; операции (добавление/удаление/done) работают корректно.
- [ ] При ширине экрана 390 px интерфейс читаем; нет горизонтального скролла.

## Additional Checks

- [ ] Прогресс корректно пересчитывается при любых изменениях списка.
